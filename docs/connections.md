# 🔗 Connections

CryptoBot supports two connection types.

---

## 🏦 Exchanges (CEX)

Connect using API keys inside the app.

Supported:

* Binance
* Bybit
* OKX
* KuCoin
* Kraken
* Bitget
* Gate.io
* Bitfinex
* Coinbase

---

## 💼 Wallets (Web3)

Connect instantly via secure popup.

Supported:

* MetaMask
* Trust Wallet
* Coinbase Wallet
* WalletConnect
* Phantom Wallet
* Rabby Wallet
* OKX Wallet

---

## 🔧 How to Connect

1. Open CryptoBot
2. Go to **Settings → Connections**
3. Choose:

   * Exchange → enter API keys
   * Wallet → connect via popup
4. Confirm connection

---

## ⚠️ Rules

* Use only **one connection type at a time**
* Exchange = API-based trading
* Wallet = Web3 connection

---

## 🔒 Security

* Never share API keys or private keys
* Disable withdrawal permissions for exchange APIs
* Always verify wallet connection requests
