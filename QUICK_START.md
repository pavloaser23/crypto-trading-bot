# Quick Start

Get **CryptoBot** up and running in a few minutes.

This guide covers downloading the application, connecting a cryptocurrency exchange or Web3 wallet, configuring a trading strategy, and starting the trading engine.

## 1. Download CryptoBot

Download the latest version from the [GitHub Releases](https://github.com/pavloaser23/crypto-trading-bot/releases).

Choose the latest release and download the application archive.

## 2. Install

After downloading CryptoBot:

1. Extract the release archive.
2. Run the installer.
3. Complete the installation.
4. Launch CryptoBot.

## 3. Launch

Start the application:

```bash
CryptoBot.exe
```

Once CryptoBot is running, open **Settings → Connections** to connect your trading account.

## 4. Connect an Exchange or Wallet

CryptoBot supports both **centralized cryptocurrency exchanges** and **Web3 wallets**.

Choose the connection type that matches how you want to trade.

### Centralized Exchanges

CryptoBot supports API-based connections to:

* Binance
* Bybit
* OKX
* KuCoin
* Kraken
* Bitget
* Gate.io
* Bitfinex
* Coinbase

Exchange connections use API credentials to access market data and execute trades.

**For security, enable trading permissions only. Never enable withdrawal permissions unless you fully understand the risks.**

### Web3 Wallets

CryptoBot also supports Web3 wallet connections:

* MetaMask
* Trust Wallet
* Coinbase Wallet
* WalletConnect
* Phantom
* Rabby
* OKX Wallet

Wallets are connected through the application's Web3 authorization flow.

Never share your seed phrase or private key with CryptoBot or any other application.

## 5. Connect Your Account

To connect an exchange:

1. Open **CryptoBot**.
2. Go to **Settings → Connections**.
3. Select **Exchange**.
4. Choose your exchange.
5. Enter your API key and secret.
6. Confirm the connection.

To connect a Web3 wallet:

1. Open **CryptoBot**.
2. Go to **Settings → Connections**.
3. Select **Wallet**.
4. Choose your wallet.
5. Approve the connection request in your wallet.

### Exchange or Wallet?

Use an **exchange connection** for centralized cryptocurrency trading through an exchange API.

Use a **wallet connection** for Web3 and on-chain trading.

Only one connection type should be active at a time.

## 6. Configure a Trading Strategy

After connecting your account:

1. Select a trading strategy.
2. Choose the market and timeframe.
3. Configure the strategy parameters.
4. Set your risk management rules.
5. Review the configuration before starting.

Available strategy types include technical analysis, trend following, scalping, arbitrage, and experimental machine-learning strategies.

## 7. Start Trading

When everything is configured:

1. Review your exchange or wallet connection.
2. Check the selected strategy.
3. Verify your risk settings.
4. Click **Start**.

CryptoBot will begin processing market data and executing trades according to the selected strategy and configuration.

## Security

Keep your trading credentials secure.

* Never share your API keys.
* Never share your wallet seed phrase or private key.
* Disable withdrawal permissions for exchange API keys.
* Use trading-only API permissions whenever possible.
* Verify every Web3 wallet connection request.
* Start with small amounts when testing live trading.
* Test strategies with historical data before using real funds.

## Troubleshooting

If CryptoBot does not connect to an exchange or wallet:

1. Check your internet connection.
2. Verify the API credentials.
3. Make sure the API key has the required permissions.
4. Check that the selected exchange or wallet is correct.
5. Review the application logs for connection errors.
6. Restart CryptoBot and try again.

## Done

CryptoBot is now installed and connected.

You can select a strategy, configure risk management, and start the trading engine.

> **Important:** Cryptocurrency trading carries significant financial risk. Always understand the strategy and risks before enabling automated trading with real funds.
