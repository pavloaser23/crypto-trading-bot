# ⚡ Quick Start

Follow these steps to run CryptoBot quickly.

---

## 1. Download

Download the latest version from the repository releases.

---

## 2. Install

* Extract the archive
* Run the installer
* Complete setup

---

## 3. Launch

Start the application:

```id="run_final"
CryptoBot.exe
```

---

## 4. Configure

Edit `config.json`:

```json id="config_final"
{
  "exchange": "binance",
  "api_key": "YOUR_API_KEY",
  "api_secret": "YOUR_SECRET"
}
```

---

## 5. Start Trading

* Open CryptoBot
* Select a strategy
* Configure risk settings
* Click **Start**

---

## ✅ Done

CryptoBot is now running.
