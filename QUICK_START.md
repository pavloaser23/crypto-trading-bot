# ⚡ Quick Start

Follow these steps to run CryptoBot quickly.

---

## 1. Download

Download the latest version from the repository releases.

---

## 2. Install

* Extract the archive
* Run the installer
* Complete setup

---

## 3. Launch

Start the application:

```bash id="run_final"
CryptoBot.exe
```

---

## 🔗 Connect Account

CryptoBot allows you to connect either a **centralized exchange** or a **crypto wallet** directly from the application interface.

---

### 🏦 Supported Exchanges

Connect using API keys directly inside the app:

* Binance
* Bybit
* OKX
* KuCoin
* Kraken
* Bitget
* Gate.io
* Bitfinex
* Coinbase

---

### 💼 Supported Wallets

Connect instantly via secure Web3 integration:

* MetaMask
* Trust Wallet
* Coinbase Wallet
* WalletConnect
* Phantom Wallet
* Rabby Wallet
* OKX Wallet

---

### ⚠️ Notes

* Use **one connection type at a time** (Exchange OR Wallet)
* Exchanges require API keys with **trading permissions only**
* Wallets are connected via secure authorization (no manual setup required)

---

### 🔧 How to Connect

1. Open **CryptoBot**

2. Go to **Settings → Connections**

3. Choose connection type:

   * **Exchange** → enter your API key & secret
   * **Wallet** → connect via secure popup (Web3)

4. Confirm connection

---

### 💡 Tips

* Use **Exchange** for centralized trading (API-based)
* Use **Wallet** for Web3 / on-chain trading
* Make sure only **one connection type is active**

---

## 4. Start Trading

* Select a strategy
* Configure risk settings
* Click **Start**

---

## ⚠️ Important Notes

* Use **one connection type at a time** (Exchange OR Wallet)
* Never share your API keys or wallet access
* Disable withdrawal permissions for exchange APIs
* Always verify wallet connection requests

---

## ✅ Done

CryptoBot is now ready to trade.
